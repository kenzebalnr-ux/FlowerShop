# 4-зертханалық жұмыс — CRUD және сүзгілер

## Мақсат

Тауарларды толық басқару, іздеу мен баға диапазоны арқылы каталогты сүзу және қате жағдайларды дұрыс өңдеу.

## Сценарийлер

- **Create:** әкімші атау, сипаттама, баға, категория, сурет және қойма санын береді.
- **Read:** каталог, жеке карточка, іздеу және сүзу.
- **Update:** PATCH тек жіберілген өрістерді ауыстырады; PUT толық ауыстыру сценарийін қолдайды.
- **Delete:** тауар физикалық жойылады. Бұрынғы тапсырыс жолында `product_id` бос қалады, бірақ атау мен сол кездегі баға сақталады.

`search`, `min_price`, `max_price` параметрлері URL query жолында беріледі. Сүзгілер SQLModel өрнектері арқылы құрылады; пайдаланушы енгізген мәтін SQL кодына тікелей жалғанбайды. Минимум максимумнан үлкен болса, сервер сұрауды қабылдамайды.

## Қорғау сұрақтарына жауап

1. **PUT пен PATCH айырмасы?** PUT ресурс көрінісін толық ауыстырады; PATCH берілген өрістерді ғана өзгертеді.
2. **Query-параметр деген не?** URL-дің `?search=раушан&min_price=5000` бөлігіндегі қосымша шарт.
3. **Optional және None?** Optional өріс жіберілмеуі мүмкін дегенді білдіреді. `exclude_unset=True` жіберілмеген өрісті анықтайды; тыйым салынған нақты null бөлек тексеріледі.
4. **Жою алдында ID неге тексеріледі?** Жоқ ресурсты 404 арқылы дәл хабарлап, бизнес шектеулерді тексеруге болады.
5. **CRUD сәйкестігі?** Create — POST, Read — GET, Update — PUT/PATCH, Delete — DELETE.
