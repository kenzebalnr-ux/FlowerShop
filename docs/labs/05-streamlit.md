# 5-зертханалық жұмыс — Streamlit интерфейсі

## Мақсат және құрылым

`frontend/streamlit_app.py` — зертханаға арналған деректерді басқару интерфейсі. Ол `requests` кітапханасы арқылы FastAPI-ге HTTP сұрау жібереді. Каталог кестесі, мәтіндік іздеу, баға және категория сүзгілері бар. Әкімші кіргеннен кейін тауарды қосу, өзгерту және жою формалары ашылады.

Қазақша тұтынушы витринасы бөлек жасалған: каталог карточкалары, таңдаулылар, себет, тапсырыс және пайдаланушы кабинеті. Екі интерфейс бір сервер мен бір дерекқорды қолданады.

## Қолдану

1. Backend-ті іске қосу.
2. `streamlit run frontend/streamlit_app.py` командасын орындау немесе Docker Compose пайдалану.
3. `http://localhost:8501` мекенжайында каталогты іздеп көру.
4. Әкімші ретінде кіріп, тест тауарын қосу, бағасын өзгерту және жою.

API қолжетімсіз болса, қолданушыға түсінікті қазақша хабарлама көрсетіледі. Әр HTTP сұрауға timeout қойылады. Токен Streamlit сессиясында ғана сақталады.

## Нақты браузерде тексеру

Streamlit :8501 ішінде «Көктем» іздеуі 2 жол қайтарды. Жасанды әкімші тіркелгісімен кіру және №13 «Сынақ гүлі QA» тауарын қосу сәтті орындалды. Өңдеу қойындысында тауар таңдалғаннан кейін rerun кезінде таңдау сақталды. PATCH арқылы атау «Сынақ гүлі QA жаңартылды» болып өзгеріп, «Тауар жаңартылды.» хабарламасы көрінді. [Құрылымды тексеру жазбасы](../results/browser-checks.json) сақталған.

Жою операциясы нақты HTTP/API тестімен тексерілді; оны Streamlit интерфейсінде орындалған әрекет деп көрсетпейміз.

## Қорғау сұрақтарына жауап

1. **UI мен API қалай сөйлеседі?** HTTP арқылы; сұрау мен жауап деректері JSON форматында беріледі.
2. **params және json?** `params` URL query жолын жасайды; `json` сұрау денесін JSON ретінде жібереді.
3. **Backend өшсе не болады?** Сұрау connection error немесе timeout береді; UI exception-ды ұстап, түсінікті хабарлама шығарады.
4. **Streamlit неге қайта орындалады?** Әр widget өзгерісі скриптті қайта жүргізеді. `session_state` бірнеше іске қосылу арасындағы күйді сақтайды.
5. **Артықшылық пен шектеу?** Python-мен деректер интерфейсін тез жасауға болады, бірақ күрделі тұтынушы дизайны үшін HTML/CSS/JS көбірек еркіндік береді.
