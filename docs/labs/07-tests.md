# 7-зертханалық жұмыс — Автоматты тест және қорғау

## Мақсат

API мен бизнес логиканы қайталанатын тесттермен тексеру және жобаны іске қосу тәртібін құжаттау.

## Қамту

FastAPI TestClient сұрауларды бөлек uvicorn процесінсіз орындайды. Тесттер production деректерін өзгертпеу үшін оқшауланған БД және dependency override қолданады. GET, POST, PUT/PATCH, DELETE, қате кіріс, жоқ ID, рөл және тапсырыс сценарийлері тексеріледі. Нақты тест саны мен нәтижесі [8-зертхана есебінде](08-testing-report.md) көрсетіледі.

## Қорғау реті

1. README бойынша жобаны іске қосу.
2. Витринадан каталог, іздеу, себет және тапсырысты көрсету.
3. Streamlit ішінде әкімші CRUD әрекеттерін көрсету.
4. `/docs` арқылы API сұрауын орындау.
5. `pytest` нәтижесін көрсету.
6. ER байланыстары мен файлдардың міндетін түсіндіру.

Git тарихындағы күндер нақты жұмыс уақытын көрсетеді. Жоба бір сессияда жасалған болса, оны жеті апта бойы жасалғандай көрсетуге болмайды.

## Қорғау сұрақтарына жауап

1. **Автотест не үшін керек?** Өзгерістен кейін негізгі мінез-құлық бұзылмағанын қайталанып тексереді.
2. **TestClient-ке uvicorn керек пе?** Жоқ, ол ASGI қолданбасын тест процесінде шақырады.
3. **httpx рөлі?** HTTP клиенті және заманауи ASGI тест құралдарының тәуелділігі.
4. **AI review пайдасы?** Қосымша сценарийлер мен ықтимал кемшіліктерді ұсынады, бірақ адам тексеруін және нақты тестті алмастырмайды.
5. **Регрессия деген не?** Жаңа өзгерістен кейін бұрын жұмыс істеген мүмкіндік бұзылады. Бұрынғы сценарийлерді автоматты қайталау оны ерте анықтайды.
